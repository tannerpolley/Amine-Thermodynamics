# Absorber inputs beyond thermodynamic equilibrium

For [MEA-Absorption-Column#85](https://github.com/tannerpolley/MEA-Absorption-Column/issues/85), a thermodynamic parameter record is only one input to a rate-based column. The column also needs reaction rates, molecular transport and packing-specific transfer relations. This document lists gaps; it authorizes no column implementation or parameter adoption.

The descriptions below come from read-only inspection of CESAR-1 at the supplied commit `f24611b95a0fa62bd41b99c1bfd8d700fc6ddd2a`. They describe implementation choices, not verified published correlations. No source code, private fitted coefficient or pilot measurement is reproduced. Where the code has no traceable literature citation, that is stated rather than assigning a familiar correlation name by inference.

The eNRTL application uses water as the solvent reference with infinite-dilution electrolyte reference conventions; it distinguishes apparent feeds from true reacting species. CO2 uses a Henry-law treatment, solvent vapor pressures supply volatile neutral species, and ionic reactions couple true-species activities. Its fitting folders separate unloaded binary, single-amine loaded and mixed-amine data. Those structural choices are useful as an index, but its eNRTL interaction coefficients and local rate/transport fits are not transferable PC-SAFT evidence. The general file header still mentions MEA; the descriptions above follow active classes and assignments rather than that header.

## Pilot campaigns as candidate validation

CESAR-1 contains separate SEPPL and TCM campaign folders and absorber case runners. The SEPPL index includes case operating inputs and axial temperature/loading profiles; TCM likewise has campaign-specific case inputs and profile comparisons. These are potential tests of coupled equilibrium, kinetics, heat/mass transfer, hydraulics and heat loss. They cannot isolate thermodynamic error by themselves.

No pilot condition, row count, observation, fitted correction or case result is retained here. The files are private transcriptions, unchecked against original campaign publications. Before use, identify the public campaign report, apparatus/packing, inlet flow/composition/loading/temperature, measurement uncertainties, steady-state criteria and any original model calibration. Partition whole campaigns for calibration versus validation; a pilot run used to fit area/kinetic corrections is not an independent column test. The exact public SEPPL/TCM report identities remain unresolved in this inspection; do not infer them from filenames.

[Column issue #85](https://github.com/tannerpolley/MEA-Absorption-Column/issues/85) requests a solvent declaration containing the thermodynamic hand-off and these user-supplied transport/kinetic quantities. Its body describes #228 as unbuilt; that historical statement is superseded by the merged #228 comments. The present remaining thermodynamic export limitation is ePC-SAFT#928 (native fitted parameter JSON serialization), not absence of a fitting driver. This scoping task neither opens Engine requests nor changes the column tracker.
