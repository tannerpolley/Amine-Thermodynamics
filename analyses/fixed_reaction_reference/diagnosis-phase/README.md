## Reproduction

Use the project interpreter with the pinned wheel installed and its archive in the normal build/engine-wheels location. From the root, run each Python file with PYTHONPATH=src and process affinity restricted to study cores (e.g. taskset -c 0-3). The shared starts module verifies the wheel bytes. Run pressure.py, then fraction.py, neighbors.py (first normally, then with --dense), roots.py and outcomes.py. Run parents.py with and without --search. Run controls.py before cap.py; run closure.py separately with mea and dea. Use born.py alone and with --direct. The JSON records retain wall seconds per probe and per case when available. Temperatures are K, absolute pressures Pa, molar densities mol/m³ and loadings mol CO₂/mol amine. Historical status strings, trial messages and alternate seeds remain in the original or linked records.

**Born-off AMP control (one historical feed).** At 393.15 K and 2.03724 MPa the retained feasible mixture of two liquid roots lowers Gibbs by 0.3637575 mol relative to the homogeneous Born-off parent. This is an upper bound on minimum Gibbs and demonstrates a model instability (a). It does not supply the equilibrium amounts. Reproduce the known lower-energy feasible split before solving coexistence. To decide amounts, start a constrained Gibbs minimization at this *feasible mixture*, holding C, H, N, O and charge inventories fixed, with both phase amounts and reaction extents free. Use log-amount or active-face coordinates for trace species and follow any vanishing species to its face. Pass when the split closes the material and charge balances, each occupied phase satisfies its reaction affinities, neutral exchange potentials agree, and the attained Gibbs lies at or below the feasible mixture within its estimated error. Check the constrained second variation. Report alternate feasible minima separately. The Gibbs upper bound excludes a homogeneous minimum but does not establish an interior two-liquid stationary point; no amounts are promoted.

**Exact follow-up for the two single-trial failures.** At the offset MEA feed solve the offending near-pure-0 stationarity equations in scaled coordinates using its reported terminal composition and packing (search.json.gz), and compare the resulting tangent-plane value and sign interval with the original trial.
