\section*{Data and Code Availability}
% P:availability-01
The A7 data release DOI is pending.
The release will contain processed observations, selected parameters, retained calculations and presentation inputs; the analysis repository is \url{https://github.com/tannerpolley/Amine-Thermodynamics}.
Its README identifies the evidence commit, file roles, omitted dependencies and reproduction commands, with SHA-256 checksums for every file.
The SHA-256 of the selected parameter file is \nolinkurl{e234e8601ebc47b3dec25383ee0a0a8029cabb9f7f92c87866f595c505c7e58e}; the evidence commit, including the analysis notebook, is \nolinkurl{8f40c125e5945ac785cc0ad1889fc79bea2096c9}.
A7 calculations use the ePC-SAFT Engine software from the private repository \url{https://github.com/tannerpolley/ePC-SAFT}, at commit \nolinkurl{8298c6029ebb8b467929badc4a223c580ec591ab}, with wheel SHA-256 \nolinkurl{8897a0caab9f2508ed642f42c8b5226957fbe7035ed7bfdad71e4166798785b3}.
The Engine wheel is not bundled with the planned A7 data release; reproducing the thermodynamic calculations requires access to that dependency.
The earlier F1 deposit, DOI \nolinkurl{10.5281/zenodo.23323107}, does not contain this A7 release.
The repository software and original documentation use the MIT licence; third-party measurements retain their source terms.
The Supplementary Material distinguishes A7, A6 and predecessor software identities.
