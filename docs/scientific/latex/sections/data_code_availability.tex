\section*{Data and code availability}
% P:availability-01
The electronic data comprise processed observations, parameter values, numerical results and the analysis and figure code under the MIT license; third-party measurements remain under the terms of their sources.
The electronic data are deposited on Zenodo at \url{https://doi.org/10.5281/zenodo.24623748}.
The reported values were calculated with an unreleased version of the epcsaft package, later than release 0.1.0, whose source is at \url{https://github.com/tannerpolley/epcsaft}.
The deposit contains the installable package used, the model inputs, the calculation results and the commands that regenerate every table and figure of the article and the supplement from them.
The model inputs are the processed observations with their transformations from the source tables, the caloric inputs and the full parameter vectors of the four models.
