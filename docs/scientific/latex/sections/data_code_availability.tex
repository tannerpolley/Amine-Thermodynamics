\section*{Data and code availability}
% P:availability-01
The electronic data comprise processed observations, parameter values, numerical results and the analysis and figure code under the MIT license; third-party measurements remain under the terms of their sources.
The Zenodo DOI will be assigned at submission.
The reproducibility package is 252.76 MB, with a SHA-256 checksum list covering \num{2671} files.
It contains the archived epcsaft wheels used for the reported models (version 1.3.1) and for the earlier MEA calculations (version 1.3.0), with source revisions and checksums in the software index and replay commands in the README.
It also contains the full parameter vectors of the four reported models and the comparison fits of \cref{tab:amine-summary}, caloric inputs, source-row transformations, and calculation outputs including failed evaluations.
Three executable examples replay the MEA heat of absorption, the DEA split at 30 wt\% and a loading of 0.50, and the Gibbs pressure- and temperature-derivative check at the selected MEA bubble state (Table~\ref{supp-tab:supplement-fixed-reference-consistency}).
The DEA example is deposit ID 32, which is processed source row 33 of the Weiland et al.\ densities, because deposit IDs start at zero; processed source row 32 is the adjacent unresolved state at a loading of 0.45.
The current public release, version 1.3.2, with its source at \url{https://github.com/tannerpolley/epcsaft} and a conda package installed with \texttt{conda create -n epcsaft -c conda-forge -c tannerwpolley python=3.13 epcsaft=1.3.2}, was not used for the reported calculations, and whether it reproduces them has not been tested.
