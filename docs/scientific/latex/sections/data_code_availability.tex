\section*{Data and Code Availability}
% P:availability-01
The processed observations, parameter files, calculation scripts, results and figure data supporting this article are archived on Zenodo, \url{https://doi.org/10.5281/zenodo.23323107}, as release \nolinkurl{manuscript-fpe-v1} of \url{https://github.com/tannerpolley/Amine-Thermodynamics} (MIT licence).
The ePC-SAFT software used for all calculations is attached to that GitHub release as a binary wheel with its SHA-256 hash; its source code is not public.
The Supplementary Material lists the calculation files and software identities.
