# Bülow pressure-gap diagnosis

The [notebook](notebook.qmd) owns the diagnosis and source locators. None of the
tested alternatives explains the complete-isotherm gap. This is numerical
diagnosis, not physical validation. Primary results and parameters are unchanged.

`probe.py` computes the two predeclared one-factor dielectric alternatives on
63 previously qualified rows. `compare.py` retains row and isotherm comparisons;
`present.py` renders their signed pressure errors. `digitize.py` segments the
published Figure 4 orange trace for the installed CSE XY digitization helper.
See the notebook for commands, inputs, limitations, and remaining unknowns.
Independent scientific review remains open.
