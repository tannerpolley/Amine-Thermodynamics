\section*{Data and code availability}
% P:availability-01
The electronic data comprise processed observations, parameter values, numerical results and the analysis and figure code under the MIT license; third-party measurements remain under the terms of their sources.
Deposit identifier: \textit{[Zenodo DOI supplied in the final submission]}.
The deposit holds the full parameter vectors of the four reported models, of the fits with the MEA-fitted shared set, of the first AMP fit and of the three MDEA fits of Table~\ref{supp-tab:mdea-shared-control}, and its README lists the package versions, linear solvers, checksums and commands needed to repeat the calculations.
The four reported models were calculated with version 1.3.1 of the epcsaft package and the MEA fits with the MEA-fitted shared set with version 1.3.0; version 1.3.2 is public, with its source at \url{https://github.com/tannerpolley/epcsaft} (release v1.3.2) and a conda package installed with \texttt{conda create -n epcsaft -c conda-forge -c tannerwpolley python=3.13 epcsaft=1.3.2}.
