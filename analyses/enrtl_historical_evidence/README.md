# Historical eNRTL evidence

This directory retains five compact evidence classes from the immutable
`codex/enrtl-two-leaf-nine-species` history through `e514120`:

1. six-species fixed-state parity;
2. nine-species species/ion-pair interaction topology;
3. the 64-row grouped fixed-composition screen;
4. its separate reaction-residual range; and
5. the distinct D01 equilibrium-continuation result.

The record is exploratory and historical. The 64 designs are not equilibria,
and D01 is not a process-model result. No current parameter set is adopted.
Unavailable caloric values, executable historical code, machine-local paths,
generated process-facing output, and the oversized source JSON are omitted.

`results/historical_evidence.json` is the compact retained record. Its source
commit/blob identities and the conversion receipt preserve provenance without
copying the old runtime. The protected
`analyses/enrtl_six_species_ideal_comparison` analysis is intentionally not
modified.
