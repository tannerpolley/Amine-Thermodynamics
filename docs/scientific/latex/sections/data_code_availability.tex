\section*{Data and Code Availability}
% P:availability-01
Processed observations, selected parameters, retained calculations, and the code used to generate tables and figures will be deposited in Zenodo; the DOI will be added at submission.
The deposit README will identify the exact software versions, file checksums, omitted dependencies and reproduction commands.
The analysis code is available at \url{https://github.com/tannerpolley/Amine-Thermodynamics} under the MIT license; third-party measurements retain their source terms.
Thermodynamic calculations require the compiled ePC-SAFT Engine package, which will be supplied to referees through restricted access arranged by the corresponding author.
The data deposit and restricted package access are to be completed at submission.
