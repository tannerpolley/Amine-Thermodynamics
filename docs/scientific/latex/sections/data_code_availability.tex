\section*{Data and code availability}
% P:availability-01
The electronic data comprise processed observations, parameter values, numerical results and the analysis and figure code under the MIT license; third-party measurements remain under the terms of their sources.
The Zenodo DOI will be assigned at submission.
The reported values were calculated with a development build of the epcsaft package after release 0.1.0, whose source is at \url{https://github.com/tannerpolley/epcsaft}.
The deposit contains that wheel; the retained inputs, which are the processed observations with their source-row transformations, the caloric inputs and the full parameter vectors of the four models; the retained calculation records; and the commands that regenerate every table and figure of the article and the supplement from them.
