\section*{Data and Code Availability}
% P:availability-01
Processed observations, selected parameters, retained calculations, and the code used to generate tables and figures will be deposited in Zenodo; the DOI will be added at submission.
The deposit README will identify the exact software versions, file checksums, omitted dependencies and calculation commands.
The analysis code will be included in the deposit under the MIT license; its development repository is \url{https://github.com/tannerpolley/Amine-Thermodynamics}. Third-party measurements retain their source terms.
Every fit and every displayed value was calculated with the author's ePC-SAFT implementation (Python package \texttt{epcsaft}, source commit \texttt{3e83e19c}).
The deposit README specifies the checksum of its immutable wheel, and the compiled library will be supplied to referees through restricted access arranged by the corresponding author.
