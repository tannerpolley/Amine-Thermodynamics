## Authority rule

Native GitHub issues are the live queue. A canonical context or program states
durable decisions. A literature review supplies source synthesis. An analysis
README or report states what was actually run. Historical plans and handoffs
remain readable provenance but cannot silently reactivate or supersede current
decisions.
