\section*{Data and Code Availability}

The processed observations, parameter files, calculation results and figure data are available at \url{https://github.com/tannerpolley/Amine-Thermodynamics}, commit \nolinkurl{79256a09ba0f3c4a3afdceabd4d1595c927a6d08}.
The selected SSM+DS parameter set, F1, is in \nolinkurl{analyses/mea_parameter_bundle/results/selected-current-best-parameters.json}, SHA-256 \nolinkurl{ae92bac5d2ef7ab690e692f6b1686e18cf06f24ac6b53a6aab4fafeb3046f1aa}.

All fits and evaluations used the \texttt{epcsaft} software build (Python wheel) with SHA-256 \nolinkurl{28181e72e429c6e87fc6361082af1a7b21c8747e76bda65a1c30abb4a97402f2}.
The estimation of the fixed R2 and R5 shifts is retained in \nolinkurl{analyses/mea_parameter_bundle/results/reaction-temperature-fit/}.
The figures and result tables of this manuscript are drawn from those files by \nolinkurl{analyses/mea_parameter_bundle/scripts/render_manuscript_figures.py} and \nolinkurl{docs/scientific/latex/scripts/final_rerun_tables.py} in the manuscript sources of the same repository.
