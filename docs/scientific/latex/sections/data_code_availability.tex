\section*{Data and code availability}
% P:availability-01
The electronic data comprise processed observations, parameter values, numerical results and the analysis and figure code under the MIT license; third-party measurements remain under the terms of their sources.
Deposit identifier: \textit{[Zenodo DOI supplied in the final submission]}.
% PENDING: confirm the reviewer package contents against this paragraph before submission.
The deposit is a reproducibility package with file checksums and executable examples: the MEA heat of absorption, the DEA split at 30 wt\% and a loading of 0.50, and the check of \cref{eq:pressure-tracking}.
It will hold the full parameter vectors of the four reported models and of the comparison fits of \cref{tab:amine-summary}, of the first AMP fit and of the three MDEA fits of Table~\ref{supp-tab:mdea-shared-control}, and its README lists the package versions, linear solvers, checksums and commands needed to repeat the calculations.
The four reported models were calculated with version 1.3.1 of the epcsaft package and the MEA fits with the MEA-fitted shared set with version 1.3.0; the software index of the deposit identifies the exact build and source revision of each, and the deposit will include both builds.
The current public release, version 1.3.2, with its source at \url{https://github.com/tannerpolley/epcsaft} and a conda package installed with \texttt{conda create -n epcsaft -c conda-forge -c tannerwpolley python=3.13 epcsaft=1.3.2}, was not used for the reported calculations, and whether it reproduces them has not been tested.
