\section*{Data and code availability}
% P:availability-01
The electronic data comprise processed observations, parameter values, numerical results and the analysis and figure code under the MIT license; third-party measurements remain under the terms of their sources.
Deposit identifier: \textit{[Zenodo DOI supplied in the final submission]}.
A software index in the deposit lists the versions, checksums and commands needed to repeat the calculations.
The MEA calculations were made with version 1.3.0 of the epcsaft package, and the DEA, MDEA and AMP calculations with version 1.3.1.
Recalculated with version 1.3.1 at the reported parameters, the fitted MEA quantities differ from the reported values by less than $2.1\times10^{-12}$ in relative terms, and all 2646 phase-stability searches again finish without a detected instability.
Version 1.3.2 of the package is publicly available: its source is at \url{https://github.com/tannerpolley/epcsaft} (release v1.3.2), and a conda package is installed with \texttt{conda create -n epcsaft -c conda-forge -c tannerwpolley python=3.13 epcsaft=1.3.2}.
Built from that source for Linux and Python 3.13 with the HSL MA57 linear solver, which is licensed separately, version 1.3.2 reproduces the reported predictions of all four amines at the reported parameters: the fitted MEA quantities differ from the reported values by less than $2.1\times10^{-12}$ in relative terms, all 2646 MEA phase-stability searches again finish without a detected instability, and five searches that did not finish with version 1.3.1, one for DEA and four for MDEA, now finish without a detected instability, while every search that finished before still finishes.
The conda package uses the MUMPS linear solver and does not require MA57; checked on MEA only, its 307 fitted MEA predictions agree with those of the MA57 build within $1.4\times10^{-12}$ in relative terms.
The MEA fit and the refits near the bound were not repeated with version 1.3.1, and no fit was repeated with version 1.3.2.
